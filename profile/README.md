# Phanes Labs

**Open-source software — from infrastructure tooling to consumer apps.**

We build lean, production-ready projects across different domains: self-hosted infrastructure, networking tools, and apps that deserve a proper open-source alternative. Everything here is built with an enterprise mindset — without the enterprise price tag.

Phanes Labs is the open-source home of [@jannik-schroeder](https://github.com/jannik-schroeder).
